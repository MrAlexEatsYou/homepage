HTTPS Certificate Setup

To avoid certificate warnings and get a clean padlock in your browser, download and install the Caddy CA certificates on your device.

Important for mobile apps (especially Immich): You need to install both certificates - the Root CA and the Intermediate CA.

📥 Download Root CA 📥 Download Intermediate CA

Installation Instructions:

  • macOS: Double-click both certificates → System Keychain → Trust → Always Trust
  • Windows: Double-click both certificates → Install Certificate → Local Machine → Trusted Root Certification Authorities
  • iOS/iPadOS:
    • Download both certificates (email to yourself or use Safari)
    • Install both profiles: Settings → General → VPN & Device Management
    • Enable trust: Settings → General → About → Certificate Trust Settings → Enable both "Caddy Local Authority" certificates
  • Android:
    • Settings → Security → Advanced → Encryption & credentials
    • Install a certificate → CA certificate → Install both certificates

After installing both certificates, restart your browser/app and you will see a clean padlock 🔒 on all services. Mobile apps (like Immich) require both certificates to connect successfully.
